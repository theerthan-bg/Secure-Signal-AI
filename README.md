# 🛡️ SecureSignal AI

> **Detect. Verify. Protect.**

SecureSignal AI is an AI-powered cybersecurity platform developed for the **SEBI Securities Market TechSprint Hackathon**. The platform helps investors identify AI-generated fraud, including deepfake videos, voice cloning, phishing emails, fake websites, QR-code scams, and manipulated financial communications.

---

## 🚀 Problem Statement

AI-generated synthetic media and phishing attacks are rapidly increasing in financial markets. Fraudsters exploit deepfakes, cloned voices, fake websites, and phishing campaigns to deceive investors.

SecureSignal AI provides real-time detection, verification, and AI-powered trust scoring to protect investors and strengthen trust in securities markets.

---

# ✨ Features

- 🎥 Deepfake Video Detection
- 🎤 AI Voice Scam Detection
- 📧 Phishing Email Detection
- 🌐 Fake Website Detection
- 📱 QR Code Verification
- 🛡️ Official Communication Verification
- 📊 AI Trust Score (0–100)

# 🎯 Workflow

1. User uploads suspicious content.
2. AI analyzes media using multiple detection engines.
3. Trust Score Engine calculates fraud probability.
4. Explainable AI generates evidence.
5. Users receive alerts and recommendations.
